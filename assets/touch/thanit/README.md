# ThanitMay_71 symbols

Extracted from the supplied Illustrator EPS via Ghostscript PDF and Poppler SVG.
SVG files retain vector paths and gradients; PNG files are transparent 512×512 exports.
The preview uses a dark background for inspection only.

Includes steering arrows, camera, brake, accelerator, nitro and pause.
Circular frames and scene background were excluded. EPS transparency flattening
has left scene-coloured bands inside the accelerator and pause artwork;
these are source artifacts, not fully restored clean masters.

These are candidate assets only; RaceControlsView has not been changed.
Source licensing is not recorded in the supplied files.
