# Сравнение GIL_EAGER на Android

Один APK поддерживает оба режима через `debug.nfsu.gil_eager`:

- `1` — прежний Android-режим: некоторые ожидающие потоки раньше запрашивают
  вытеснение держателя GIL;
- `0` — контрольный режим без eager-запросов; очередь GIL и её таймауты остаются;
- пустое или недопустимое значение — `1`; недопустимое значение отмечается в логе.

Сам GIL остаётся включённым. Переключатель не меняет аудио, Vulkan и настройки
игры. Значение читается перед стартом гостевых потоков и действует до завершения
процесса. Возврата через Home недостаточно: нужен полный перезапуск.

## Порядок A1 → B → A2

Собрать один раз обычным корневым `./gradlew assembleDebug`, установить APK.
Выключить подробную диагностику для всех трёх запусков:

```bash
adb shell setprop debug.nfsu.diagnostics 0
```

Запуск A1:

```bash
adb shell setprop debug.nfsu.gil_eager 1
adb shell am force-stop org.nfsu.android
adb shell am start -n org.nfsu.android/.LauncherActivity
```

Вручную открыть главное меню после выбора того же профиля, оставить Quick Race.
Подождать 30 секунд в меню, затем измерять FPS и время кадра 60 секунд одним
и тем же способом. Не менять машину, настройки, режим питания и подключение
зарядки. Отмечать заикания звука. Подтверждение режима в `nfsu1.log`:

```text
[ANDROID] detailed diagnostics=0
[ANDROID] GIL eager=1 (debug.nfsu.gil_eager)
```

Сохранить журнал до следующего перезапуска:

```bash
adb pull /sdcard/Android/data/org.nfsu.android/files/nfsu1.log gil-a1.log
```

Запуск B — выполнить те же команды с `debug.nfsu.gil_eager 0`, повторить вход
в меню, 30 секунд прогрева и 60 секунд замера. Сохранить лог как `gil-b.log`.
В startup-логе должно быть `GIL eager=0`.

Запуск A2 — снова `debug.nfsu.gil_eager 1`, полный перезапуск, та же сцена,
прогрев и замер. Сохранить лог как `gil-a2.log`.

Сравнить FPS, медиану и P95 времени кадра. Если A1 и A2 сильно расходятся,
пока нельзя приписывать отличие B переключателю. Даже при улучшении меню
нужна отдельная проверка гонки, звука и автосохранения.

Для возврата к прежнему режиму оставить свойство `1` и перезапустить игру.
Это отладочное свойство обычно сбрасывается после перезагрузки телефона;
при отсутствии свойства используется тот же режим `1`.
